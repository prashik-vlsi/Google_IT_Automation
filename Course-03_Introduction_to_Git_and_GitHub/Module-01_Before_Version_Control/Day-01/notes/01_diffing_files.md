# Day 01: Diffing Files

## What is version control?
Version control tracks changes to files over time.

## What is Git?
Git is a version-control tool used to record and manage project history.

## What is diff?
The Linux diff command compares two files and shows their differences.

## Important commands
- cp: Copies a file.
- diff old.py new.py: Compares two files.
- diff -u old.py new.py: Shows differences in unified format.
